# V10 header and footer sizing

- Homepage instruction font has not been changed. The same `Standard` font stack is explicitly applied to other pages. The original font binary has not been recovered, so browsers may display Arial fallback.
- Footer remains fixed, bottom-aligned and single-row. Archived `post-95.css` specifies navigation item padding 15px above and below, 51px horizontal menu-item margin, and left offset 50px on large desktop, 30px on tablet, 25px on mobile.
- Approximate reconstructed desktop footer height: **47px**, tablet **47px**, mobile **38px** (CSS estimates derived from archive padding and font metrics, not a historical measured footer height).
- The instruction-list active header and About-page content start at the top of their content area, rather than beneath additional synthetic top padding.
- The homepage has no invented top header; site navigation remains in the bottom footer.
- This is a CSS layout pass, not a pixel-matched browser capture verification.
